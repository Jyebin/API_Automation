BUG-007 쿠폰 발행 가능 여부 조회 — 조건 미충족 시 422 반환
심각도: Medium 재현율: 항상 (발행 조건 없는 계정) 비즈니스 규칙 오류
대상 API
GET /api/v2/coupon/issue/available
재현 절차
  1. 쿠폰 발행 조건을 충족하지 않는 계정(raontestqa1)으로 로그인하여 JWT 발급
  2. GET /api/v2/coupon/issue/available 요청
기대 결과
200 OK — 발행 불가 상태를 응답 본문으로 반환 예: { "available": false }
실제 결과
422 Unprocessable Entity — 발행 조건 미충족을 에러 코드로 처리
수정 제안
가능 여부를 "조회"하는 API이므로 조건 미충족 시에도 200 + { "available": false }로 반환하는 것이 적절. 현재 동작은 조회 API를 처리 API처럼 설계한 것으로 보임
